# Litt

Clean Roblox starter using Rojo 7.

Run `rojo serve default.project.json` from this folder. Connect the Studio
Rojo plugin to localhost:34872 and accept the sync. Press Play and check
Output for `Litt connected through Rojo! Ready for a fresh start.`

Server code goes in `src/server`; client code in `src/client`.
Stop Play before syncing changes. The previous prototype was removed;
its code remains recoverable in Git history.
